# **App Name**: CampusOS

## Core Features:

- Role-Based Authentication: Implements email-based authentication with automatic role detection (Director, Academic Office, Doctor, Student, Faculty/Staff) based on email domain and prefixes.
- Student Dashboard: Personalized dashboard for students with schedule, AI-powered schedule planner, campus intelligence feed, resource hub, document submission, availability checker, burnout detection and Gemini AI chat integration for doubt clearing. Gemini acts as a tool that Student Dashboard uses.
- Faculty/Staff Dashboard: Dashboard for faculty and staff to manage class schedules, availability, AI-assisted missed class rescheduling, and student overviews.
- AI Smart Schedule Engine: Generates conflict-free, personalized schedules using student/faculty IDs, enrolled subjects, institute timetable, room availability and personal events. The LLM acts as a tool for reasoning and conflict resolution when scheduling conflicts arise.
- Document Management System: Handles document uploads, approval workflows, status tracking, and notifications to streamline administrative tasks and eliminate physical document handling.
- Curriculum Intelligence Module: Offers detailed UG curriculum information by department (CSE, ECE, AIDS) and semester, integrated with related resources and schedules to facilitate effective academic planning.

## Style Guidelines:

- Primary color: Deep blue (#1A237E) to evoke trust, intellect, and institutional reliability. The choice of blue reflects a professional environment suitable for an academic platform.
- Background color: Light blue-gray (#E8EAF6), nearly desaturated from the primary color for a clean, unobtrusive background that supports readability.
- Accent color: Warm yellow (#FFB300), analogous to blue-green, to highlight calls to action and important interactive elements, providing a visual contrast that draws the user's eye without disrupting the calm of the primary palette.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, providing a techy and modern look; 'Inter' (sans-serif) for body text to ensure readability and a neutral appearance in longer text blocks.
- Use a set of clean, minimalist icons to represent different actions, resources, and modules within the platform. Icons should be visually consistent and support quick comprehension.
- Employ a grid-based layout to ensure a structured and responsive design across different screen sizes. Dashboards should prioritize key information with clear sections and intuitive navigation.
- Incorporate subtle animations for transitions and interactions to provide feedback and enhance the user experience without being distracting. For example, loading indicators, sliding panels, or hover effects.
